 Bonus round 
 
This game genie code should get you the very same pairs at every battle, on Puyo Puyo 2 (REV 00) (J) [Genesis]:
 Code: Select all 9VGA-AGJ0 
T7GA-BLJ2 
6KGA-B5A4 
97GA-AAA6
GVGA-ADJ8
 
It patches the following bytes:
 Code: Select all ROM:4C16 move.b (a2,d0.w),(a2,d1.w) ; Move Data from Source to Destination
ROM:4C1C move.b d2,(a2,d0.w) ; Move Data from Source to Destination
 
which are handling the color-set shuffling, by replacing them with:
 Code: Select all move.l #$35879DE2,($FFA134).l
 
Which resets the current value of the RNG. This is called once at every start of a battle. The result is you'll always get the same puyos with colors yellow, red, green and blue. 
 
You can actually choose what puyos you'll get by varying the RNG value, defined by the game genie codes T7GA-BLJ2 6KGA-B5A4. The tool "Game Genie Code Converter" can help you compute new values. 
 
The code should work on real hardware. Could anyone confirm that? 
 
 
Beyond that, here's what tricking the game looks like, based on the previous reverse engineering: 
 
 
Here's what we've done:
 
 defined a particular pair order to fill the upcoming pool buffer with. This was done to get the perfect pieces for our "insane niagara", at the right time, while not having to rotate them; 
 swapped a yellow puyo for a blue in the P1 falling pair before triggering the 1-chain; 
 filled the P1 board with puyos to get the crazy 1-chain. They are invisible because video updates are triggered only when you actually place a puyo. 

Notice the rest of the pairs are all double reds. The puyo swapping (yellow for blue) is purposely visible for only 1 frame.

 A quick addition as it has been requested on IRC. 
 
The following are game genie codes that will force Puyo Puyo Tsuu to use a 4-color set only, or set the falling speed. 
 
These codes forces 4-color mode in both single player and 2p versus modes :
 Code: Select all ABGA-ACE6 
ABGA-ACE8 
ABGA-ACFC 
ABGA-ACFE
 

The next code will set the falling speed to normal in 2p versus mode only , regardless of the chosen difficulty:
 Code: Select all AB3A-BAG6
 

The following code will set the falling speed to the lowest available setting throughout single player mode only :
 Code: Select all JB3A-AETW
 

The next 2 codes will set falling speed throughout single player mode to the normal speed of 2p versus mode :
 Code: Select all JB3A-AETW
AB3A-BAC6
 

Note: due to how the game works, it is not possible to set a different speed for the player and the CPU in single player mode (with help of game genie codes anyway). Doing so requires heavy hacking, and patching a whole subroutine.

 For those interested, the following game genie code will turn the game into a pseudo endless mode :
 Code: Select all ABSA-AAGA
 
Tested and works on Puyo Puyo 2 (REV 00) (J) [Genesis] . 
Tested and works on real Genesis hardware . 
 
The code makes the game ignore the fact that a player has his third column full. The consequence is a deadlock in which the game will indefinitely loop through the pairs it should deal to the losing player. The other player can continue until his board is also full, at which point you should reset the console as there is no way the game will ever end. Ojama puyos will still fall upon an opponent (I haven't found which routines handle ojama puyos yet) . 
 
Note: although the game appears to loop and do nasty things, it will not harm your console or cartridge. 
 
Edit: Rom hackers who want to make this permanent may edit their rom and change the byte value at 0x005EC1 from 0x01 to 0x00. No need to edit the rom's checksum, the game doesn't care about its value.
